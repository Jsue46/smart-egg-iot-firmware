# Smart Egg — IoT System with Firmware and Frontend

Academic project developed for the **Computer Architecture and Assemblers 2** course at the Universidad de San Carlos de Guatemala (Second Semester 2026).

This repository contains the full implementation of an IoT system called **SmartEgg**, including embedded firmware, a web frontend, and supporting documentation. The project was developed collaboratively as a group assignment.

---

## Overview

SmartEgg is an IoT device system designed to monitor and manage physical conditions through embedded firmware and a connected web interface. The system integrates hardware-level programming with a modern frontend to provide real-time control and visualization.

---

## Technologies

- **Firmware:** C++
- **Frontend:** TypeScript, CSS, HTML
- **Backend/Scripts:** Python, PowerShell, Shell
- **Containerization:** Docker
